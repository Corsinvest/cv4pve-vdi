## Why

The Proxmox VE web interface is built for administrators. Someone who only needs to *use* a few VMs
(a developer with a test machine, an office worker on a Windows desktop, a thin client in a lab) has to
log into it, find the VM in the tree, open the console menu, download a `.vv` file for SPICE, or look up
the VM's IP address before opening RDP.

cv4pve-vdi puts those VMs in one window. It logs in with the user's own Proxmox VE account, so each person
sees only what the Proxmox permissions allow, and opens the connection with one click: SPICE or VNC through
`remote-viewer`, RDP or SSH through the tools already on the computer, with the IP address read from the
QEMU guest agent.

## On your computer, API only

cv4pve-vdi is a desktop application for Windows, Linux and macOS. It runs on the user's computer, not on the
nodes, and talks to the Proxmox VE REST API on port 8006: nothing is installed on the cluster and no agent
runs on the nodes. SPICE goes through the `spiceproxy` every node already runs, VNC is tunnelled through the
API port itself; see [How it connects](/cv4pve-vdi/how-it-connects/).

The only other connection it makes is to GitHub, to check for a new release at start-up and then every
12 hours.

## Where it fits

| | **cv4pve-vdi** | [cv4pve-pepper](https://github.com/Corsinvest/cv4pve-pepper) | [cv4pve-admin](https://corsinvest.github.io/cv4pve-admin/) Resources | Proxmox VE web UI |
|---|---|---|---|---|
| **For** | People who use VMs | Scripts and terminal users | Administrators, in a browser | Administrators |
| **Runs** | Desktop application | Command line | Web application | Browser |
| **Connects with** | SPICE, VNC, RDP, SSH, custom tools | SPICE, VNC | noVNC, xterm.js, SPICE | noVNC, xterm.js, SPICE |
| **Access** | Proxmox VE API, the user's own account | Proxmox VE API | Proxmox VE API | - |

cv4pve-pepper is the command-line companion: one command opens a SPICE or VNC console. The console buttons of the
[Resources](https://corsinvest.github.io/cv4pve-admin/modules/resources/) module in cv4pve-admin serve
administrators who already work in its web interface.
